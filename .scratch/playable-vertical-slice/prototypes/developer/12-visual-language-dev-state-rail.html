Throwaway developer prototype · Bold and Brave · issue 12 · developer set

State Rail

Tradeoff Determinism and inspectability over motion: the URL is the source of truth and every battle state is a station on a rail, so reviewers can jump straight to any state, share it as a link, and inspect each object. There is no animation loop at all — only CSS transitions — and a live DOM-node counter exposes the browser cost of each HUD density mode.

HUD DOM nodes: 0 · Scene SVG nodes: 0 · page total: 0. Same information, three costs — pick the readability bar that fits the browser budget.

No animation loop in this version; the only motion is CSS. Keys 1 / 2 / 3 switch density.

State rail — battle states

Every click rewrites the URL (?state=&settlement=&guard=&attack=&hold=&density=&fate=) — states are shareable links, and the page boots into whatever the URL says.

Directional telegraph — guard vs attack

Where the Band guards (gold) vs where the attack comes from (red). A Directional Guard matching the telegraph fully negates it and opens a recoil window; a Shield Block would cover every sector while held, at stamina cost (see the stamina meter).
